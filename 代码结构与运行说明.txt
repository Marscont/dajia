EnKF 同化代码结构与运行过程说明
=================================

一、项目目标
-----------
本项目用于对 WRF 模式输出的 CO2 场进行集合卡尔曼滤波（EnKF）同化，支持：
1) 选择同化区域（d01 / d02 / d03）；
2) 读取卫星与地面（或其他近地）CSV观测；
3) 两步同化流程：先同化近地面浓度，再同化卫星柱浓度（XCO2）；
4) 输出后验排放、后验浓度场及诊断信息。


二、代码文件结构
---------------
1. config_init.py
   - 定义 Config 数据结构。
   - 负责读取 configure.yaml。
   - 创建输出目录（output_base_dir/targettime/assim_domain）。

2. configure.yaml
   - 运行配置文件。
   - 定义同化域、wrfout路径、观测源、误差参数、膨胀设置、集合成员数等。

3. data_loading.py
   - 读取 WRF 数据：网格、CO2分量、气压、几何高度。
   - 计算总 CO2：CO2_ANT + CO2_BCK + CO2_BIO - co2_system_bias。
   - 读取观测 CSV，并按时间、值域、3σ规则做基础筛选。
   - 构造初始集合（扰动先验场）。

4. observation_operators.py
   - 实现柱浓度压力权重计算。
   - 实现卫星平均核（AK）XCO2 观测算子。
   - 实现近地层（如50m/100m）插值观测算子。

5. spatial_matching.py
   - 使用 wrf.ll_to_xy 将观测经纬度映射到 WRF 网格索引。
   - 过滤掉落在域外的观测。

6. enkf_assimilation.py
   - EnKF 核心更新（分析步）。
   - 支持 fixed/adaptive inflation（固定或自适应通胀）。

7. main_controller.py
   - 主控流程入口。
   - 按“surface -> xco2”顺序执行两步同化。
   - 组织匹配、构造观测算子输出、调用EnKF、保存结果。

8. save_concentrations.py
   - 保存后验 2D 表层浓度 NetCDF。
   - 保存后验 3D 浓度 NetCDF。

9. save_emissions.py
   - 保存后验排放 NetCDF。


三、关键计算逻辑
---------------
1) 总CO2计算
   total_co2 = CO2_ANT + CO2_BCK + CO2_BIO - co2_system_bias

2) 地面/近地观测算子
   - 对每个观测点提取该网格的垂直 CO2 廓线 + 高度廓线；
   - 在配置高度（surface_interp_height_m，如50m）处进行线性插值；
   - 得到 H(x) 与观测值 y 比较后进入 EnKF。

3) 卫星XCO2观测算子（AK）
   - 将 WRF CO2 按卫星给定 pressure_levels_0..19 插值；
   - 使用 pressure_weights_from_boundaries 计算层权重 w_i；
   - 根据公式计算：
     XCO2 = xco2_apriori + Σ [ w_i * A_i * (CO2_i(interp) - CO2_apriori_i) ]

4) EnKF分析更新
   - 计算集合协方差 Pxy 与 Pyy；
   - 结合观测误差 R 得到卡尔曼增益 K；
   - 进行扰动观测更新，得到后验集合 Xa。


四、运行流程（main_controller.py）
---------------------------------
1. 加载 configure.yaml；
2. 创建输出目录；
3. 读取目标域 wrfout、网格信息、模式变量；
4. 读取并筛选观测；
5. 基于先验场构造初始集合 Xf；
6. 第一步：遍历 type=surface 的观测源执行同化；
7. 第二步：遍历 type=xco2 的观测源执行同化；
8. 计算后验均值场并写出：
   - posterior_emission.nc
   - posterior_surface_co2.nc
   - posterior_3d_co2.nc
   - diagnostics.json
   - matched_*.csv


五、输入数据要求
---------------
1. WRF文件
   - 三个域分别提供 wrfout（d01/d02/d03），在 YAML 中通过 wrfout_files 指定。

2. 卫星CSV（xco2）
   - 至少需要：Latitude, Longitude, xco2, xco2_uncertainty
   - AK计算还需要：xco2_apriori, pressure_levels_0..19,
     co2_profile_apriori_0..19, xco2_avg_kernel_0..19
   - 若包含 time 列，格式为 YYYY-MM-DD-HH，可按 targettime 过滤。

3. 地面/近地CSV（surface）
   - 通过 YAML 中 observation_sources 自定义列名映射：lat/lon/val/err。


六、如何运行
-----------
1. 修改 configure.yaml：
   - 设置 targettime；
   - 设置 assim_domain（通常 d02）；
   - 填写 wrfout_files 各域真实路径；
   - 设置 obs_root_dir 和各 CSV 文件名；
   - 检查 num_members、co2_system_bias、inflation 等参数。

2. 执行：
   python main_controller.py

3. 结果检查：
   在 output_base_dir/targettime/assim_domain/ 下查看输出文件。


七、常见问题排查
---------------
1. 没有任何观测参与同化：
   - 检查 time 过滤条件；
   - 检查 val_range 与 3σ 过滤是否过严；
   - 检查观测经纬度是否落在当前域内。

2. XCO2计算报错（缺列）：
   - 检查 20 层列是否齐全：pressure_levels_*, co2_profile_apriori_*, xco2_avg_kernel_*。

3. 结果不稳定：
   - 调整观测误差（xco2_uncertainty 或 default_err）；
   - 调整 inflation 参数（fixed 或 adaptive范围）；
   - 适当放宽或收紧 sigma_threshold。


八、建议后续增强
---------------
1. 将 matching_method 扩展为 bilinear（当前主要为 nearest）；
2. 增加显式局地化矩阵并按域分辨率自动缩放半径；
3. 完善多时次循环同化（start_time/end_time批处理）；
4. 增加单元测试与回归测试样例。
